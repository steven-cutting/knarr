# Decision 0006: Apache-2.0

Adapted on 2026-10-07 from libpawdoku’s [0006-apache-2-0.md](https://github.com/steven-cutting/libpawdoku/blob/51d8b55ac4f769a6a4d66abacb9642a7d4062127/docs/decisions/0006-apache-2-0.md) at commit `51d8b55ac4f769a6a4d66abacb9642a7d4062127`. The source record remains in its original repository.

## Decision

Knarr uses Apache-2.0, as recorded in the repository's [LICENSE](../../LICENSE). This carries the source project's single-license choice into this repository. A single established license makes the project's distribution terms explicit without introducing a second license option during bootstrap.

The license file is authoritative. This record explains the repository choice and does not add new legal terms, contributor agreements, or dependency-policy machinery. Root maintainer documentation belongs to ticket 12.

## Consequences

Copied material needs compatible provenance and permission; choosing a repository license does not supply permission for unrelated upstream code. [Decision 0004](0004-gate-checkers.md#provenance-and-licence) records the copyright holder's grant for the copied checker files, whose headers retain source attribution and an SPDX identifier.

The source project's Rust dependency-license gate is not present in Knarr and is not claimed here. Any future licensing checks need to match the dependencies and tooling this repository actually uses. A change to distribution terms would require a new explicit decision rather than an incidental metadata edit.
