# Project direction and scope

Knarr targets autoscaled worker fleets with uneven task durations. The repository is being bootstrapped around a Gleam controller on the BEAM, a specification-first workflow, and a read-only local quality gate. This section points to the existing direction documents without promoting proposals into accepted behaviour.

- [Overview](../OVERVIEW.md) defines the proposed MVP and identifies open questions.
- [Deferred options and research](../DEFERRED.md) preserves alternatives and post-MVP ideas.
- [Bootstrap work](../../.scratch/bootstrap/README.md) records the implementation lanes and their dependencies.
- [Decisions](../decisions/README.md) records choices that have already been settled.

The overview and deferred research remain at their original paths so existing links continue to work. Behavioural contracts belong to the specifications as those are introduced; this navigation page does not replace them.
