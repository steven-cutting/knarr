# Checksum-pinned downloads for tools conda-forge does not carry (Decision
# 0003, "Escape hatch"). scripts/install-tools.sh, run by `just initialize`,
# installs the host platform's lines into the gitignored .tools/bin and refuses
# any download whose sha256 differs from the pin.
#
# One line per tool and platform:
#   name version platform url sha256 member
# `member` is the basename of the file to take from a .tar.gz archive, wherever
# it sits inside; for a plain download it is the downloaded file itself. Every
# URL is https. A lane that adds a tool copies its lines from
# .scratch/bootstrap/evidence/01/tools.txt (or rehashes a new version) and adds
# both platforms.
#
# ripsecrets 0.1.11 predates GitHub's asset digests and publishes no checksum
# file: its sha256 is a first-use pin computed on 2026-10-07 (Decision 0003).
