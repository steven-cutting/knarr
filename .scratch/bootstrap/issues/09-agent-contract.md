# 09: Agent contract

## Hand-back notes

Implemented on 2026-10-07 on branch `09-agent-contract`.

- **`AGENTS.md`** states the six invariants the ticket names, in the `improve-claude-md` shape: bare identity, project map, the specs-decide-what rule and the untrusted-input rule, then a bare Invariants list and one `<important if="...">` block per task kind (Gleam code, specifications, docs, the agent surface, a failing gate or hand-back, picking up a ticket). There is no commands table; each block names only the recipes it uses and `just --list` is the index. `CLAUDE.md` is exactly `@AGENTS.md` and `.github/copilot-instructions.md` is one byte-pinned paragraph; both are the `[agents.adapters]` values in `checks.toml`.
- **`validate_agents.py`** is copied from biscuit_games_tooling `v0.3.0` (`6c5c07f6`, sha256 `24c59cae…4807d350` confirmed locally) per Decision 0004. `required_guidance`, `tolerated`, `bridges` and `adapters` come from `[agents]` and fail closed with status 2; managed directories and the bridge body's `../` depth derive from `[agents.bridges]`; the `CODEX.md` check is gone. The phrase list is 0004's proposal plus 07's `docs/specs/`: eleven phrases, matched case-insensitively. 88 CLI tests in `scripts/checks/tests/test_validate_agents.py`, every one asserting that validation writes nothing.
- **Vendoring.** `juxt/allium` tag `v3.16.0`, commit `7f7f008e0c6b0a17cc81f5cb1c05a4b923cd63c2`, cloned once into `ai_tmp/` under the network grant. The seven skills (`allium`, `distill`, `elicit`, `propagate`, `tend`, `weed`, `witness`) are byte for byte in their upstream layout, `references/` beside each `SKILL.md`, which reverses libpawdoku's root relocation (its decision 0010) because the validator now permits exactly the files the lock lists under a vendored directory. The upstream MIT `LICENSE` is copied into each skill directory and hashed in that skill's lock entry. Every one of the 30 upstream blobs under `skills/` matches `git -C ai_tmp/allium ls-tree -r HEAD skills` by blob id, and the seven `LICENSE` copies match upstream's `LICENSE` blob (`60347341`). `allium-tools` stays at 3.6.1; the skills target language version 3.
- **The lock.** `skills-lock.json` lists 37 files (30 upstream plus 7 licences), equal to `find` over the seven directories. The validator checks it in both directions: a listed file must exist with its sha256, and a file under a vendored directory must be listed. The lock is generated by the validator's read-only `lock` mode, so the hashes come from the code that checks them; `lock` mode on this tree reproduces the committed file byte for byte. A fresh lock prints a placeholder `source` whose commit is not hex, and the gate refuses it until the provenance is written, because a shell redirect over the lock truncates it before `lock` mode can copy `source` from it (the page documents printing into `ai_tmp/` first).
- **No Copilot bridge directory.** GitHub's agent-skills documentation lists `.agents/skills/` as a project skill directory, so Copilot reads the canonical skills natively. `[agents.bridges]` is `claude = ".claude/skills"` only, so there are fourteen bridges. `tolerated` is empty: no plugin is enabled, so nothing is committed under `.claude/` but the bridges, and `.claude/settings.local.json` stays ignored.
- **Linters at 3.16.0.** Without exclusions, typos flags only `JUXT` in the seven `LICENSE` copies, and markdownlint reports more than 450 findings on the 23 vendored Markdown files (`MD040`, `MD060`, `MD032` and `MD031` lead); editorconfig-checker passes. Offline lychee checks 97 links inside them with no error and one excluded, and no link leaves the vendored subset, so lychee stays on. The vendored directories are excluded in both prek configs, `.markdownlint-cli2.jsonc`, `_typos.toml` and `.gitattributes`, so that a re-vendor never changes a gate result and `just fix` never rewrites upstream bytes. `MD033` allows the `important` element and `MD041` is off, because a bridge body is fixed by the validator and `CLAUDE.md` is one line.
- **Baseline fix.** `just check` was red on this branch before any 09 work: Decision 0008, merged from ticket 15 after 06, was missing from `docs/manifest.yml`, unreachable, and required a predicate `checks.toml` does not declare. Fixed in the first commit (manifest entry, `requires: []`, decisions index item 8).
